PROJECT 04

QuickMart – Weekly Data Pipeline & Leadership Report

An end-to-end pipeline that turns three messy raw CSV extracts (customers, products, 6,103 orders) into a trusted dataset of 3,052 validated orders, five datamarts, and an LLM-written executive report, refreshed weekly with zero code changes.

Python PostgreSQL Pandas SQL LLM (OpenRouter) GitHub Actions
  • Cleaning & Dedup: Canonical ID maps for fuzzy IDs (C0001 vs C-0001) and rule-based deduplication, taking 6,103 raw orders to 6,000 and flagging ghost customers and products.
  • Validation & Datamarts: Seven validation rules (price ±5%, quantity, dates, delivery status) feeding five datamarts: sales, customer value, payments, delivery, and quality.
  • Verified LLM Report: A Markdown leadership report with no PII, where every figure is checked against the datamarts, plus a model card.

PROJECT 05

HCLS Healthcare Data Crisis – Audit-Ready Pipeline

A five-phase data-engineering response for a healthcare network with broken claims, records, and visits data. It audits 20 sheets with 289 rules, finds 149 issues (the brief reported only 3), and delivers finance reconciliation, a safe fix plan, and an audit pack, running nightly on Databricks.

Python SQL / SQLite Databricks Delta Tables Power BI GitHub Actions
  • Data Quality & Root Cause: 289 YAML-driven rules with transparent severity scoring, plus 27 hypotheses tested with seeded statistics.
  • Finance Reconciliation: An 18-line waterfall labelled certain vs estimated, with three scenarios giving a defensible revenue-gap range instead of forcing the brief's figures to match.
  • Safe Remediation: Fixes on a copy only, with quarantine, exact rollback, 13 safety checks, and a five-sign-off approval gate.
  • Audit Pack & Automation: A 65-number evidence register, a hash-chained audit trail, a Power BI dashboard, and 507 tests across six layers.
  • Databricks Orchestration: Jobs, schedules, and triggers set up on Databricks, with email alerts on start, stop, and failure.
